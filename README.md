# Rabbit Hole

A local curiosity explorer. Ask a question and Gemini turns it into an interactive knowledge graph.

## Run locally

**Prerequisites:** Node.js 20+

1. Install dependencies:

   ```bash
   npm install
   ```

2. Copy the env file and add a [Gemini API key](https://aistudio.google.com/apikey):

   ```bash
   cp .env.example .env.local
   ```

3. Start the app:

   ```bash
   npm run dev
   ```

4. Open [http://127.0.0.1:3000](http://127.0.0.1:3000).
